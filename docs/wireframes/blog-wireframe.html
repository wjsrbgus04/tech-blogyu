엣지 런타임의 커넥션 문제

Workers는 요청마다 격리된 컨텍스트에서 실행되기 때문에, 프로세스가 살아 있는 동안 커넥션을 재사용하는 전통적인 풀링 전략이 통하지 않습니다. 매 요청 TCP 핸드셰이크를 새로 하면 왕복 지연이 그대로 응답 시간에 얹힙니다.

요약하면, 엣지에서는 "연결을 오래 붙잡는" 최적화가 아니라 "연결을 아예 만들지 않는" 최적화가 필요합니다.

HTTP 드라이버로 전환

Neon은 Postgres 와이어 프로토콜을 HTTP로 감싼 서버리스 드라이버를 제공합니다. 커넥션 개념 자체가 없어져 Workers와 궁합이 맞습니다.

Drizzle 설정

import { drizzle } from 'drizzle-orm/neon-http'
import { neon } from '@neondatabase/serverless'

const sql = neon(env.DATABASE_URL)
export const db = drizzle(sql, { schema })

남은 제약

  • 트랜잭션은 단일 HTTP 요청 안에서만 묶을 수 있습니다.
  • 커서 기반 스트리밍은 지원되지 않습니다.
